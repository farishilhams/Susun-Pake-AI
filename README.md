# Susun Pake AI — AI-Powered Architecture & Spec Generator

This is a Next.js 15 (App Router) + TypeScript project integrated with MongoDB Atlas, NextAuth.js, and multi-provider AI streaming (Google Gemini, Groq, OpenRouter) for **Susun Pake AI** — Platform Otomatis Pembuat Dokumen Arsitektur & Spesifikasi Proyek Software.

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start exploring and modifying the application by editing components in `src/app/` or primitive components in `src/components/ui/`. The page auto-updates as you edit the file.

This project uses:
- **Tailwind CSS** for modern theme-adaptive "Cinematic Glass" styling
- **Shadcn UI & Radix UI** for accessible primitive components
- **Framer Motion** for fluid animations (magnetic buttons, parallax, marquee)
- **Lucide Icons** for clean, modern interface iconography
- **MongoDB Atlas & Mongoose** for cloud database persistence
- **NextAuth.js** for dual-method authentication (Credentials & Google OAuth)
- **Multi-Provider AI Router** with streaming fallback (Gemini 2.5 Flash, Groq, OpenRouter)
